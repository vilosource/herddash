### Diff-scope review (bmad-review: adversarial and edge-case lenses; verification-gap lens run inline, narrowed)

**Checked and sound:**
- The race between subscribing and the initial snapshot: `events.go:140-216` against
  `engine/view.go:215-221`.
- Slow-client close.
- The engine change list against the Board model on one stream, including removal before an epoch
  increments (`engine.go:1029-1031`).
- Wire field names, pinned on both sides.
- Host-header case and IPv6 handling.
- A `waiting_since` in the future clamps to 0s.

**Findings:**
- **D1 (medium). A hung Daemon is never shown as lost.**
  - The keepalive is an SSE comment, `": keepalive\n\n"` (`events.go:267-268`), which EventSource
    never passes to the page.
  - `streamLost` keys only on `error` events (`order.mjs:360-362`).
  - So a wedged or SIGSTOPped Daemon, or a half-open socket, leaves undimmed stale Boxes with no
    strip. That undermines FR-5's "never trust a stale Board".
  - Still present at HEAD (`events.go:267`). **Fix.**
- **D2 (low). A `state` event that fails validation leaves the Board merging into, or frozen on, a
  stale model.**
  - `awaitingState` is re-armed only by board.mjs's own `open` step (`order.mjs:330-331`), not by
    EventSource's automatic reconnect.
  - A rejected `state` returns only a warning (`order.mjs:342-343`) and does not mark the stream
    lost.
  - Downgraded from the reviewer's medium: it needs the Daemon to emit a malformed `state`.
  - Still present at HEAD. **Fix**, bundled with D1.
- **D3 (low). The Board ignores `id:` (the view seq), and at 6fce275 also ignored `run_id`.**
  - At HEAD a `run_id` change reloads the page (`45bcd64`).
  - A skipped delta (an unknown change kind dropped server-side at `events.go:228`, or an event
    `applyEvent` rejects) goes unnoticed until the stream drops.
  - **Fix**, bundled with D1: treat a seq gap as a lost stream and reopen it.
- **D4 (low/medium). Workspaces with no known position merge under one header with the wrong
  name.**
  - Every lower-zone Agent with `workspacePosition <= 0` gets `Group = SortUnknown`
    (`core/view.go:197-203`).
  - The header label comes from the first view in the group (`order.mjs:121-124,140-143`).
  - Still present at HEAD (`view.go:291`). **Fix** (low priority). It happens only when herdr
    omits a workspace's position.
- **D5 (medium, verification gap). The no-gap SSE test uses a fake engine ordering the real engine
  cannot produce** (`events_test.go:318-336`). No test runs the real `engine.Subscribe` and `View`
  against `serveEvents`. Still present at HEAD. **Fix** (test).
- **D6 (medium, verification gap). No test replays real engine publications through
  `applyEvent` and compares the result with `View.Agents`.**
  - The cases that matter are epoch-change mass removal, remove-then-re-add, and the
    final-check changes.
  - No divergence was found by reading the code; the agreement is assumed, not tested.
  - **Fix** (test). A Go test can dump a publication sequence as a fixture that `order.test.mjs`
    replays, the same pattern as the golden order fixture.
- **D7 (low). `/api/state` and the static assets set no write deadline, and the server has no
  `IdleTimeout`** (`httpapi.go:172-182`, `board.go:79-85`, `serve.go:142-146`). Loopback only.
  **Defer.**
- **D8 (low). Pane-title text handling.**
  - The glyph strip eats a leading `-`, `#` or emoji in a session name, and a bare `✳` survives
    (`core/view.go:31-35`).
  - Bidi and format characters (Cf, for example U+202E) pass `oneLine` (`core/view.go:56-64`),
    and the Context Line is not wrapped in `<bdi>` (`board.mjs:63-79`).

  **Fix** (low): the Context Line is the one Box field a pane's process controls.
- **D9 (low). The version strip says "herdr (version unknown) is below the supported minimum"
  when the version could not be read** (`order.mjs:436-456`; `gate.go:31-49` refuses an empty
  version). Still present at HEAD (`order.mjs:512`). **Fix** (wording).
- **D10 (low). The history endpoint is unbounded, and it orders by `observed_at, id` rather than
  append order** (`history.go:90-124`, `store/record.go:180-188`). **Defer.** It has no consumer
  yet.
- **D11 (low). The raw `pane_title` rides on every view, and a title change that leaves the
  Context Line unchanged still emits an `agent` event** (`core/view.go:120,151`,
  `engine/view.go:175`). **Accept.** It is part of the AC's AgentView field list.
- **D12 (low, verification gap). `board.mjs` drawing runs in no CI check.**
  - The check covers `place`/group reuse, focus restore, strips, dimming and refused hiding.
  - At 6fce275 `web/check/board-browser.mjs` covered strips only. Box and group checks came later
    in `8fa1bf4`.
  - **Fix: covered by Story 5.6.**

### Aggregate views

- **A1. Architecture delta: clean.**
  - The new edges are cmd→httpapi, httpapi→core and httpapi→engine, all in `arch_test.go`'s
    permitted set, and `arch_test.go` is unchanged in the range.
  - The permitted httpapi→store edge goes unused.
  - **Accept.**
- **A2. The wire contract is owned by three packages.**
  - The `/api/state` shape is set by JSON tags on `engine.View` (`engine/view.go:17-29`).
  - The `AgentView` and `SortKey` JSON is set in core (`core/view.go:105-124,256`).
  - The SSE payload types are in httpapi (`events.go:53-86`).

  **Defer.** Worth one paragraph in the spine naming where each part of the public JSON lives;
  folded into the R9 DOCS item.
- **A3. Duplication.**
  - Ordering exists in both Go and JS. That is intentional and fixture-pinned, apart from
    code-point string comparison and epochs above 2^53.
  - Workspace headers are computed three times: core, the `headers` wire field, and `order.mjs`.
  - Agent keys are turned into strings three different ways.
  - JSON writing is split between an encoder and `writeJSON`.

  **Accept**, except that the unused `headers` wire field could be dropped. **Defer.**
- **A4. Size: `internal/httpapi/web/order.mjs` grew 0 → 465 lines (32 exports) in the epic and is
  591 lines (49 exports) at HEAD.**
  - It holds five concerns: ordering, formatting, the event reducer, the stream state machine and
    the strips.
  - `engine/engine.go` grew only slightly in Epic 3 (1610 → 1661 lines), but is 2369 lines at
    HEAD.
  - `serveEvents` is one 145-line function (`events.go:135-280`).
  - **Defer**, with a process lesson: split `order.mjs` by concern the next time a story touches
    it.
- **A5. Pattern divergence: minor.** `httpapi.New` panics on nil options while `engine.New` does
  not validate. Tests in the new packages use one test per scenario and rarely `t.Run`. **Accept.**
